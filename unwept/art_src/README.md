# UNWEPT art source

Every illustration in `UNWEPT_Arc1_Ch1_Comic.html` is hand-written SVG vector art, generated by these scripts.

| File | What it draws |
|---|---|
| `art.py` | Core kit: shapes, gradients, glow filters, speed lines, rain, cracks, SFX, system windows, pixel art |
| `hair.py` | Hair locks, highlights and every character's hairstyle |
| `chars.py` | Cast configs (colors, eyes, marks), heads, expressions, bust outfits, back-of-head view |
| `figures.py` | Full-body standing figures and props (bread, lantern, rapier, glaive, greatsword) |
| `beasts.py` | The Hush, Murmur, Wail, Dirge, Lament, Crumb |
| `scenes.py` | Backgrounds (rain funeral, apartment, void, silt, drowned ruins), hands, phones, controller, pixel game screens |
| `panels.py` | Chapter 1: all 60 panels with lettering |
| `build.py` | Assembles the cover, character sheets and chapter into one HTML file |

Rebuild (Python 3.8+, no dependencies):

```bash
cd unwept/art_src && python3 build.py ../UNWEPT_Arc1_Ch1_Comic.html
```
